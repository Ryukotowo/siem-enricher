# Структура проекта

Каталог `siem-enricher/` — самодостаточный проект: исходный код, конфигурация, ML-контур,
тесты, инструменты демонстрации и развёртывание.

```
siem-enricher/
├── README.md                     Обзор, быстрый старт, состав модулей
├── pyproject.toml                Пакет, extras (service/es/kafka/ml/transformer/dev), настройки линтеров
├── requirements.txt              Боевые зависимости (сервис, коннекторы, политики)
├── requirements-ml.txt           ML-зависимости: torch (CPU) + transformers + sklearn
├── requirements-dev.txt          Инструменты разработки: pytest, ruff, mypy
├── Dockerfile                    Образ сервиса (ARG INSTALL_ML=0|1, веса монтируются томом)
├── docker-compose.yml            Стенд: Kafka + enricher + Redis + заглушка SIEM (+Prometheus/Grafana)
├── Makefile                      Короткие команды (make test, make smoke, make replay)
├── .env.example                  Переменные окружения (Kafka, ML, политики)
│
├── config/                       Конфигурация и правила (данные, не код)
│   ├── config.example.json       Боевой профиль: источник и приёмник Kafka, SQLite для provenance
│   ├── config.local.json         Локальный профиль: файловый реплей, память, человекочитаемые логи
│   ├── config.docker.json        Профиль Docker: Kafka, multi-приёмник (Kafka + файл + webhook)
│   ├── policies.json             9 правил применения политик (условия + действия)
│   └── sensitivity_labels.json   Классы конфиденциальности, веса риска, отображение категорий модели
│
├── src/siem_enricher/            Исходный код сервиса
│   ├── __init__.py               Версия пакета
│   ├── __main__.py               `python -m siem_enricher`
│   ├── version.py                Версия ПС и версия схемы обогащения
│   ├── config.py                 Загрузка/подстановка ${ENV}/валидация конфигурации
│   ├── logging_setup.py          JSON- и человекочитаемые логи, контекст event_id
│   ├── metrics.py                Реестр метрик Prometheus без внешних зависимостей
│   ├── audit.py                  Журнал аудита решений (JSON Lines)
│   ├── cli.py                    Команды: run, replay, serve, classify, chain, validate-config, version
│   │
│   ├── models/                   Модели данных (только стандартная библиотека)
│   │   ├── enums.py              Классы конфиденциальности, действия, типы решений и действий
│   │   ├── event.py              Каноническое событие: файлы, процессы, пользователи, адрес, правило
│   │   └── enrichment.py         Результат обогащения и документ, возвращаемый в SIEM
│   │
│   ├── extractor/                Модуль 2: извлечение метаданных
│   │   ├── patterns.py           Регулярные выражения, словари расширений, разбор путей и адресов
│   │   └── metadata.py           Псевдонимы полей SIEM, разбор Wazuh/Sysmon/ECS-документов
│   │
│   ├── ml/                       Модуль 3: классификация конфиденциальности
│   │   ├── base.py               Интерфейс классификатора, агрегация оценок по событию
│   │   ├── features.py           52 признака имени и пути (для sklearn-варианта и объяснений)
│   │   ├── fallback_rules.py     Детерминированные правила: имя, каталог, расширение
│   │   ├── transformer_classifier.py  Загрузка HF-чекпоинта (mBERT) и инференс
│   │   ├── hybrid.py             Гибрид: ML по имени + правила по размещению и пометкам
│   │   └── classifier.py         Выбор режима (auto/hybrid/transformer/sklearn/heuristic)
│   │
│   ├── provenance/               Модуль 4: происхождение файлов
│   │   ├── graph.py              Узлы и рёбра графа происхождения
│   │   ├── store.py              Хранилища: память и SQLite (+точка расширения Redis)
│   │   └── builder.py            Построение графа по событиям и восстановление цепочек
│   │
│   ├── enricher/                 Модуль 5: обогатитель
│   │   ├── risk.py               Риск-скоринг: компоненты, усиление, пороги
│   │   └── pipeline.py           Конвейер: извлечение → ML → provenance → риск → политики
│   │
│   ├── policy/                   Модуль 6: применение политик
│   │   ├── fields.py             Доступ к полям документа по путям `files[*].path`
│   │   ├── rules.py              DSL правил, операторы сравнения, разбор и валидация
│   │   ├── actions.py            Действия: маскирование, алертинг, теги, блокировка, карантин
│   │   ├── blockers.py           Исполнители блокировок: dry-run, webhook/SOAR, Wazuh API
│   │   └── engine.py             Движок: три фазы (условия → действия → решения), аудит
│   │
│   ├── connectors/               Модули 1 и 7: коннекторы к SIEM
│   │   ├── base.py               Интерфейсы источника/приёмника, реестр, MultiSink
│   │   ├── registry.py           Список доступных типов коннекторов
│   │   ├── checkpoint.py         Позиция чтения источника (для опроса и Kafka)
│   │   ├── file_replay.py        Источник из JSONL/JSON (в т.ч. режим «хвоста») и файловые приёмники
│   │   ├── kafka.py              Источник и приёмник Kafka (aiokafka)
│   │   ├── webhook.py            Приёмник webhook (REST SIEM/SOAR) с ретраями
│   │   ├── elasticsearch.py      Elasticsearch/OpenSearch: источник (search_after) и bulk-приёмник
│   │   └── wazuh.py              Wazuh Indexer как необязательный пример коннектора
│   │
│   └── service/                  Сервисный слой
│       ├── runtime.py            Среда выполнения: конвейер «источник → обогатитель → приёмник», replay
│       ├── routes.py             HTTP API: /healthz, /readyz, /metrics, /v1/enrich, /v1/classify, ...
│       └── app.py                Сборка FastAPI-приложения, запуск через uvicorn
│
├── ml/                           ML-контур
│   ├── README.md                 Формат артефакта, категории, порядок обучения и оценки
│   ├── artifacts/                Веса моделей (в git не хранятся, ~680 МБ)
│   │   └── sensitivity_transformer/   Текущая модель: mBERT, 6 категорий
│   ├── data/raw|interim|processed/    Данные: выгрузки, промежуточные чекпоинты, датасет `path,text,label`
│   ├── notebooks/                Место для исследовательских ноутбуков
│   └── training/
│       ├── build_dataset.py      Сборка датасета из генератора событий и CSV формата НИР
│       ├── train_transformer.py  Дообучение mBERT/ruBERT на именах файлов
│       ├── evaluate_transformer.py    Метрики категорий и классов конфиденциальности
│       └── train_sklearn.py      Альтернатива без torch: модель на признаках пути
│
├── tests/                        Тесты (стандартный unittest, совместимы с pytest)
│   ├── unit/                     Модульные: извлекатель, правила, гибрид, риск, поля, политики,
│   │                             provenance, конфигурация, коннекторы
│   └── integration/              Сквозной конвейер и командный интерфейс
│
├── tools/                        Инструменты демонстрации и проверки
│   ├── generate_sample_events.py Генератор событий SIEM с эталонной разметкой
│   ├── smoke_pipeline.py         Сквозная проверка ядра (18 проверок, без внешних сервисов)
│   ├── replay.py                 Обёртка для быстрого прогона файла событий
│   ├── kafka_tool.py             Публикация событий в Kafka и просмотр обогащённых
│   └── mock_siem.py              Заглушка SIEM: приём обогащённых событий по HTTP
│
├── deploy/                       Развёртывание
│   ├── docker/docker-entrypoint.sh    Режимы: serve, run, replay, shell
│   ├── k8s/siem-enricher.yaml    Deployment, Service, HPA, ConfigMap, Secret, NetworkPolicy
│   └── monitoring/prometheus.yml Конфигурация сбора метрик
│
├── scripts/
│   ├── bootstrap.ps1             Подготовка окружения и первичная проверка
│   ├── run_local.ps1             Генерация событий → обогащение → сводка (и запуск сервиса)
│   └── check_all.ps1             Линтер, типы, тесты, сквозной сценарий, проверка конфигураций
│
└── var/                          Артефакты выполнения (в git не хранятся)
    ├── logs/policy_audit.jsonl   Журнал решений политик
    ├── state/provenance.db       Граф происхождения (SQLite), checkpoint.json
    └── enriched_events.jsonl     Результаты обогащения
```

## Что где менять при доработке

| Задача | Файл |
|---|---|
| Подключить новую SIEM | добавить коннектор в `src/siem_enricher/connectors/` и тип в `config/*.json` |
| Изменить правила защиты данных | `config/policies.json` (перезагрузка через `POST /v1/policies/reload`) |
| Поправить пороги и веса риска | `config/config.*.json` → секция `risk` |
| Заменить ML-модель | положить чекпоинт в `ml/artifacts/` и указать `ml.artifact_path` |
| Изменить вход модели | `ml.text_template` (`{name}`, `{path}`, `{action}` и др.) |
| Настроить признаки размещения | `src/siem_enricher/ml/fallback_rules.py` (правила помечены `policy=True`) |
| Расширить сопоставление полей SIEM | `src/siem_enricher/extractor/metadata.py` → `FIELD_ALIASES`, `NAME_CONTEXT_SEGMENTS` |
| Добавить действие политики | `src/siem_enricher/policy/actions.py` (наследник `ActionExecutor`) |
| Добавить хранилище provenance | `src/siem_enricher/provenance/store.py` (наследник `ProvenanceStore`) |
